# Bookshelf API

A simple RESTful API for managing a digital bookshelf. Built as a portfolio project using Node.js — allows users to add, read, update, and delete books.

## Features

- Add new books to the bookshelf
- Retrieve all books or a specific book by ID
- Update book details
- Delete books from the shelf
- Filter books by reading status

## Tech Stack

- JavaScript (Node.js)
- Hapi.js Framework
